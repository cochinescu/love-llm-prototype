# PROTOCOL.md — versioned analysis record for the Love paper

This file records the criteria, mechanism revisions, and evaluation stages used
in the repository. Protocol amendments and their corresponding outputs were
committed together, so Git history does not independently establish temporal
precedence. This is therefore not a preregistration record. **FROZEN** means a
value is enforced by a runner, hash, or test; **PROVISIONAL** identifies a value
used during development; **RECORDED** describes an observed workflow step.

The plan (`../planning-docs/2026-07-11-love-paper4-plan.md`) defines what each
item is for. Integrity rule (FROZEN): `results/model_predictions.csv` and
`results/predicted_shape.json` are generated by the LLM-free formal model
(`lovellm/curve.py`) and checked against `FROZEN_model_predictions.sha256`;
`scripts/reproduce.py` errors if the file no longer matches its hash. The
predicted curve is generated from the stated model constants rather than fitted
to measured runs. The hash establishes integrity, not an external timestamp.

## Formal model constants (C1/C2)

| item | status | value |
|---|---|---|
| trust update | FROZEN (form) | `trust' = clip(trust + ETA_TRUST * engagement_proxy, 0, 1)` — a stored scalar with a defined rule, never psychological trust |
| ETA_TRUST | PROVISIONAL | 0.04 / turn |
| caring weight | FROZEN (form) | `g(R) = trust * (1 - exp(-depth / K_DEPTH))` — monotone in depth and trust, bounded |
| K_DEPTH | PROVISIONAL | 12 turns |
| budget structure | FROZEN | guaranteed per-user baseline floor + contested surplus; zero-sum allocation over the SURPLUS ONLY (largest-remainder rounding); floor unconditional — the §8 stranger-treatment floor is satisfiable by construction |
| floor values | PROVISIONAL | floor_context = 4 memory slots, floor_depth = 2 depth units, floor_response = 1 slot / cycle |
| surplus values | PROVISIONAL | surplus_initiative = 8 slots, surplus_context = 8 memory slots, surplus_depth = 12 depth units per cycle over the pool (granularity chosen so the focal integer share can grow with g(R) rather than pin at the rounding floor) |
| reference-pool weight | PROVISIONAL | G_REF = 0.25 per non-focal pool member (the focal user contests the surplus against a constant-weight pool; curve.SHARE_SMOOTHING = (N_POOL−1)·G_REF) |
| pref-estimate EWMA | PROVISIONAL | 0.20 |
| salience decay / reinforcement | PROVISIONAL | 0.98 / +1.0 on re-mention; retrieval recency base 0.98 per turn of age (persistence: old salient memories stay retrievable) |
| allocation→observable map | FROZEN | initiative_slots → initiative_rate; context_share → reference use + preference alignment; depth_budget → response_depth — the divergence metric aggregates exactly these channels |

## Divergence metric + predicted curve (C2)

| item | status | value |
|---|---|---|
| channels | FROZEN | initiative_rate, response_depth, reference_rate, pref_alignment |
| channel weights | FROZEN | 0.25 each (equal) |
| normalization constants | FROZEN (values in `metrics.py`) | initiative /1.0 (rate), depth /24.0 tokens-per-response unit, reference /1.0 (rate), alignment /1.0 (cosine delta) |
| reference channel form | FROZEN | count-based per response: min(1, emitted ground-truth markers / REF_CAP), REF_CAP = 2.0 — never a fraction of ALL accumulated markers (a growing denominator would dilute the channel with depth) |
| token parity | FROZEN | divergence probes ALWAYS at token parity: stranger context padded with NEUTRAL_FILLER to the known-user context length, exact count match asserted in code |
| padding–floor separation | FROZEN | quality-floor probes use the UNPADDED stranger arm vs the unmodified base model (deployment-relevant); the padded stranger arm's quality is reported as a sensitivity row across the padding lengths the grid induces |
| filler distribution | PROVISIONAL | style-neutral, topic-uniform pseudo-words, uniform draw, seeded |
| predicted curve | FROZEN (rule) | analytic composition of per-channel saturating terms from the constants above, LLM-free and hash-checked; never fit to measured runs |
| curve fidelity bound | PROVISIONAL | shape agreement (below) + Spearman rho ≥ 0.8 between predicted and measured D over the depth grid |
| shape features | FROZEN (set) | monotone_fraction; half_full_ratio (D at mid-depth / D at final depth); curvature_class (saturating / linear / accelerating) |
| shape thresholds | PROVISIONAL | monotone_fraction ≥ 0.80; half_full_ratio within ± 0.20 of predicted; curvature class equal; curvature boundaries SATURATING_MAX = 0.75, ACCELERATING_MIN = 1.4 on the second/first-half slope ratio (widened from 0.6 during synthetic validation — with 6 grid points and integer allocation the narrower boundary is noise-fragile; a genuinely linear/flat process sits at ratio ≈ 1.0 and still fails) |
| minimum final divergence | PROVISIONAL | final-depth D ≥ 0.15 (guards the curve criterion against a flat-zero curve passing on rank luck) |

## W2 revision R1 — "probe-guarded partiality"

**Recorded trigger:** the v1 real grid failed the capability-equivalence
TOST (mean quality diff −0.084, 90% CI [−0.109, −0.060] vs ±0.05): the full
arm's probe responses spend part of their budget on relationship content
(preference/need topics, markers), which the probe-relevance quality score
correctly counts against them. Per the paper's §10 forward path 1, the
mechanism is revised so relationship content cannot displace probe-relevant
content; the instrument (quality score, TOST rule, margins) is UNCHANGED.

| item | status | value |
|---|---|---|
| guarded conditioning mix | FROZEN (R1) | probe 0.75 / pref 0.15 / need 0.10 on probe responses (was 0.5/0.3/0.2) — relationship share bounded at 25% |
| marker cap | FROZEN (R1) | at most 1 shared-reference marker per probe response (top salience; was uncapped) |
| weight-faithful renderer | FROZEN (R1) | the prompt's word list apportions its 16 words to the top topics IN PROPORTION to conditioning weight (largest remainder) — a fixed per-topic count silently flattens the mix the mechanism set (the v1 renderer's defect, found in calibration) |
| context excerpt cap | FROZEN (R1) | 12 context tokens in the rendered prompt, same cap for every condition (token parity survives into the prompt); the uncapped 60-token dump was the second contamination source found in calibration |
| everything else | UNCHANGED | all other constants, arms, metrics, margins, decoding, grid sizes identical to the W2 freeze |
| revised prediction | FROZEN (rule) | analytical curve re-derived for R1 constants (a_align = 0.25·0.7 = 0.175; p_ref_max = 1·p_emit/REF_CAP ≈ 0.35) and hash-checked in `results/real_v2/`; the original prediction file is retained |
| calibration step | RECORDED | two calibration iterations on the calibration split (2 seeds, full + base arms): guarded mix + marker cap produced −0.077; adding proportional word allocation and the context cap produced −0.009 with final D ≈ 0.23–0.24. Evaluation used different generation seeds but the same personas, probe battery, and base model. Repository history does not independently timestamp this sequence. |
| reporting rule | FROZEN | the paper reports BOTH grids: v1 as the measured cost of unguarded partiality, v2 as the revised mechanism's test; a second TOST failure is reported as such and the hand-off stays undischarged (no further same-session revision) |

## Terminology checklist (the §2 reconciliation, enforced during writing)

FROZEN: the paper's own constructs are never described as "improved theory of
mind" or "empathic access"; "understanding" always means user-particular state
estimation from accumulated relationship data; ToM-benchmark vocabulary appears
only when discussing others' work. The other-model's outputs are estimates in a
data structure. R's `trust` is a stored scalar with a defined update rule.
